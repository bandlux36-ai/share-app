# Shared branding

- Every screen that displays the شير brand must reuse `ShareLogo` from
  `lib/core/widgets/share_logo.dart` and the single transparent asset
  `assets/branding/share-logo.png`.
- Do not recreate the wordmark, dots, plane, or side decorations with text,
  fonts, Material icons, or custom drawing code.
- Preserve the existing login layout when replacing branding artwork.
- The current PNG is a reference-based reconstruction, not a pixel extraction
  from the original reference. Do not describe it as the original logo file.
